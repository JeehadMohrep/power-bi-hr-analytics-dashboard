# Power BI HR Analytics Dashboard

A Power BI dashboard designed to analyze employee data and provide clear insights into workforce trends, salary, age, and employee attrition.

## Tools Used

* Power BI
* Power Query
* DAX

## Project Objective

The objective of this project is to analyze HR data, monitor key workforce metrics, and identify patterns related to employee attrition and workforce characteristics.

## Key KPIs

* Average Salary
* Employee Number
* Average Age
* Attrition Rate

## Key Insights

* Analyzed employee attrition and workforce characteristics.
* Examined salary and age-related metrics.
* Identified patterns in employee attrition across different workforce factors.
* Highlighted areas that can support HR decision-making.
